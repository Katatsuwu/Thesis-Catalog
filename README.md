# Fieldnotes / Lab

A static, searchable thesis-idea catalog for embedded AI, microcontrollers, edge computing, and connected sensing. It has no build step or third-party runtime dependency.

## Run locally

From the repository root:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`. Search ideas, filter by field, and select a card to read the problem, proposed direction, prototype stack, research question, and linked references.

## Research note

The catalog contains 150 research directions. The papers are IEEE starting points for methods and problem areas, not proof that the exact proposed combination is novel. They link through their DOI. Review the papers, search IEEE Xplore for recent work, confirm access and metadata, and validate the research gap with an adviser before selecting a topic.
