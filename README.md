# Fieldnotes / Lab

A static catalog for embedded AI, microcontrollers, edge computing, and connected sensing. Browse 150 complete thesis ideas or 49 problem statements in separate tabs. It has no build step or third-party runtime dependency.

## Run locally

From the repository root:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`. Choose IDEAS or PROBLEMS, search and filter by field, and select a card to read the challenge, technology opportunity, research question, suggested hardware, and linked references.

## Research note

IDEAS contains 150 thesis directions. PROBLEMS contains 49 issue statements that could be explored with embedded technology. The papers are IEEE starting points for methods and problem areas, not proof that the exact proposed combination is novel. They link through their DOI. Review the papers, search IEEE Xplore for recent work, confirm access and metadata, and validate the research gap with an adviser before selecting a topic.
